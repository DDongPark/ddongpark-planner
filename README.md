# DDongPark 분할 진입 계산기

## 파일 4개
- index.html: 입력창과 결과 화면
- style.css: 색상, 글자, 모바일 배치
- app.js: 분할 수량과 손익 자동 계산
- README.md: 업로드 안내

## GitHub에 올리는 방법
1. ZIP 압축을 풉니다.
2. 새 저장소에서 Add file → Upload files를 누릅니다.
3. 위 4개 파일을 모두 선택해서 같은 위치(저장소 최상위)에 올립니다.
4. Commit changes로 저장합니다.
5. Settings → Pages → Deploy from a branch → main → /(root) → Save를 선택합니다.
6. 배포 완료 후 Visit site를 눌러 웹사이트를 엽니다.

ZIP 자체를 업로드하거나 네 파일을 서로 다른 폴더에 넣지 마세요.
index.html은 이미지가 아니라 HTML 코드입니다. 아이폰 미리보기는 웹 화면을 보여주거나 계산 실행을 제한할 수 있습니다. 실제 사용은 배포된 웹주소를 Safari로 여세요.

## 계산 설정
- 레버리지 100배 고정
- 진입·손절·익절 모두 메이커 체결 가정
- 수수료 0.02%에서 사용자 제공 환급률 50% 반영 → 실질 수수료 0.01%
- 시드 대비 손실 배정: 1차 1%, 2차 2%, 3차 2%
- 설정 항상 표시 / 손절 손실 USDT 표시
- 목표 손익비 1:2, 1:3, 1:5 및 순수익 USDT 표시

환급 전 계좌 손실은 표시된 손실보다 클 수 있습니다. 지정가 손절은 미체결될 수 있으며 100배에서는 손절 전 청산될 수 있습니다. 이 프로그램은 주문을 실행하지 않습니다.
