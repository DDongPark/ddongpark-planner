## 이번 수정
1. `주문 방식 · 수량 단위 · 간격 설정`을 클릭하면 설정이 열리고 다시 클릭하면 닫힙니다.
2. 손실 퍼센트 기본값은 5%이며 직접 입력해 변경할 수 있습니다.
3. 총 손실률을 바꾸면 기존 1:2:2 배분 비율을 유지해 1차 20%, 2차 40%, 3차 40%로 자동 배분합니다.
   - 예: 5% → 1% / 2% / 2%
   - 예: 3% → 0.6% / 1.2% / 1.2%
